# 可画与Figma工作流

## 统一任务包

`design-brief.json` 为每个资产定义：ID、用途、画布尺寸、格式、视觉方向、构图、颜色、文字内容、文字安全区、图片安全区、提示词和目标文件名。

标准画布：首条封面900×383；正文引导图900×500；次条/方形裁切900×900；正文插画1080×720或按内容指定比例。关键主体放在中央约70%安全区。

## 可画

1. 搜索任务包中的模板关键词，而不是复制某个外部案例。
2. 新建指定尺寸画布，按安全区放置标题和主体。
3. 使用可画自带素材时，由用户确认其账号套餐与导出用途许可。
4. 导出PNG/JPG到文章包 `assets/`，按任务包目标文件名命名。
5. 运行 `prepare_assets.py` 生成微信尺寸与压缩版本。

可画只负责图片资产。除非未来存在经过验证的官方连接器，不声称可画能直接把整篇富文本同步到公众号。

## Figma

工具可用时先读取Figma相关技能并检查权限，默认在个人草稿创建文章设计文件，不写入未知团队项目。每个资产使用独立Frame，名称与资产ID一致；导出后记录文件URL和Frame ID。权限不足、工具不可用或导出失败时，回退到统一任务包，不阻塞HTML和微信草稿流程。
