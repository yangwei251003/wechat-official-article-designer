# 内容驱动视觉系统

## 先回答六个问题

1. 读者读完后应留下什么感觉？
2. 信息形状是叙事、论证、步骤、清单、时间线还是混合？
3. 文章适合沉浸慢读还是快速扫描？
4. 哪一句、哪组数据或哪幅画面应成为视觉记忆点？
5. 哪些段落需要停顿，哪些必须连续？
6. 图片承担证据、解释、情绪还是装饰？

## 视觉决策

- 配色最多三种：正文中性色、主色、少量点缀。浅底色不重复计入同一色相的色阶。
- 字号不超过四档；正文稳定，标题用字重、边框、留白和编号建立层级。
- 全文组件种类控制在2–5种。连续两段重组件会破坏阅读节奏。
- 视觉记忆点只设一个主角：封面构图、贯穿母题或核心金句屏。
- 装饰必须来自内容意象，例如航天文章使用轨道/坐标语言，而不是通用星星贴纸。

## 赛道起点（不是模板）

| 赛道 | 常用节奏 | 形态语言 | 图像倾向 |
|---|---|---|---|
| 知识科普 | 快扫与解释交替 | 细线、编号、浅底知识卡 | 示意图、概念插画 |
| 商业科技 | 数据先行、段落紧凑 | 深蓝灰、表格、强对比数字 | 抽象科技、实景证据 |
| 生活美学 | 慢读、大留白 | 暖纸色、细边框、非对称图文 | 摄影、手绘纹理 |
| 人物叙事 | 连续沉浸、少打断 | 克制标题、引语、时间节点 | 人物与环境照片 |
| 教程清单 | 步骤清晰、可跳读 | 编号、检查表、提示框 | 操作示意、图标 |

## 反平庸检查

- 是否只是给所有段落加了相同卡片？
- 标题是否有构图，而不只是换颜色？
- 图片是否在解释内容，而非随机“配一张好看图”？
- 是否用一个母题贯穿，而不是混搭多个模板？
- 去掉圆角和色块后，层级是否仍然成立？
