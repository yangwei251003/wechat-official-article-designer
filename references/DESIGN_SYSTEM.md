# 高审美视觉系统

## 0. 旧版产物不是参考

仓库根目录历史文章包、旧封面、插画、GIF、截图和 `assets/original-ornament.*` 仅用于回归与反例审计。不得提取其人物画风、奶油纸张色、左边线章节标题、卡片样式、配色或构图作为新设计起点，也不得把旧预览当成质量标杆。

当用户要求重新设计，按绿色项目处理视觉：保留被锁定的内容与品牌，不保留旧视觉语言，除非用户明确点名某一元素。

## 1. 先做 Design Read

在产出视觉前，用一句内部判断明确：文章类型、目标读者、传播动作、情绪、视觉家族和微信约束。随后设置三只旋钮：

- `DESIGN_VARIANCE`：1 对称保守，10 高差异实验。
- `MOTION_INTENSITY`：1 静态，10 强动效。微信文章通常不超过6。
- `VISUAL_DENSITY`：1 画廊式留白，10 高密信息。

公众号默认建议 `7 / 4 / 4`，但必须由内容改写：法规/医疗降低变化与动效；品牌发布提高构图冲击；儿童节可以提高变化与动效但保持可读和内容安全。

## 2. 每篇文章只用一个核心视觉概念

从核心信息提炼一个可说清的母题，例如“把复杂问题剥成三层”“从噪声里看见信号”“一封被时间折叠的信”。母题同时决定：

- 首屏构图和主图动作。
- 一种贯穿的线、形、材质或空间关系。
- 章节切换方式。
- 图片光线、镜头、材质和色彩。
- SVG/GIF的运动逻辑。

不能把星星、圆点、渐变、纸张、胶带等通用贴纸随机拼接。去掉文字后，视觉仍应与文章主题有关。

## 3. 三套方向必须结构不同

### 信息清晰型

单列逻辑、证据先行、留白分组、示意图/数据图。组件偏知识提示、对照、清单。适合高风险事实与教程。

### 品牌专业型

强品牌首屏、真实人物/产品/场景、数据或引语作为视觉锚点、统一签名。适合企业、产品发布与新闻稿。

### 视觉传播型

海报式首屏、大图停顿、短长段落交替、强视觉母题、克制GIF。适合节日、人物、文化和社交传播。

三套至少在布局家族、标题构图、组件、图片角色和运动五项中的三项不同；换色不算不同。

## 4. 微信兼容的高冲击构图词汇

微信正文不能依赖定位、Grid、Flex和脚本，但仍可通过安全结构获得设计张力：

- 海报首屏：真实主视觉 + 2行内标题 + 1句承诺，避免信息堆叠。
- 非对称双栏：用 `table` 做30/70或40/60比例，手机仍可读。
- 大数字/短句屏：只用于真实步骤、时间或数据，不伪造编号。
- 全幅图像停顿：在论证或情绪转折处使用，不按固定“每3段一图”。
- 色块章节带：同一页面不要每节都重复左边线标题。
- 引语屏：引用不超过三行，不重复正文。
- 对比/路径/时间线：内容天然具有关系时才用。
- 图文组章：图片、图注、正文形成一个语义单元，而不是图库插播。

一个长文至少使用3种节奏家族，但同类组件不要连续重复。组件不是容器税：能靠排版和留白解决时，不再套卡片。

## 5. 色彩、字体、形状

- 使用一个中性色体系、一个主色和一个强调色；强调色全篇一致。
- 不默认使用AI紫蓝光、米黄纸张+橙棕、莫兰迪万能配色或大面积渐变。
- 配色来自主题、品牌、真实图片或情绪冲突，并检查正文4.5:1、大字3:1。
- 正文使用微信系统字体栈。冲击力来自字号比例、字重、空白、行长和构图，不依赖外部字体。
- 正文字号14-16px，行高1.72-1.85；标题不靠无节制放大。
- 选择一个圆角规则：全直角、全软圆角，或明确“图片/卡片/按钮”的分级。不要混乱。

## 6. 图片与插画必须被艺术指导

真实图片或生成图的任务至少定义：主体、动作、环境、视角/镜头、光线、材质、色彩关系、留白位置、长宽比、禁止内容。示例骨架：

```text
主题与隐喻 + 主体正在做什么 + 空间/镜头 + 光线与材质 + 主色/强调色 + 标题安全区 + 指定比例 + 无文字/无水印/无品牌误用/不模仿具体艺术家
```

封面不是“好看横图”：缩略到小尺寸仍有唯一焦点，900×383裁切不伤主体，同时有900×500和方形安全变体。正文图承担证据、解释、情绪、路径中的一种。无法解释图片作用就删掉。

外部免费素材不贴合或授权不清时，直接原创。图像生成工具优先做真实质感封面/插画；`asset_factory.py`用于定制SVG母题、GIF、背景纹理和组件。不得用旧图、通用图库或空白占位伪装完成。

## 7. SVG、GIF与特效

- SVG要表达内容关系：轨迹、层级、连接、折叠、扩散、聚合等；不是随机装饰。
- 动态SVG保留为可编辑源，但微信正文引用GIF或静态PNG/JPG。
- 每个动画必须回答“它在表达什么”。有效答案是层级、顺序、变化、反馈或情绪转折；“更酷”无效。
- 默认全文最多一个主GIF。循环2-6秒、节奏平稳、体积受控、首帧可独立成立，提供静态海报。
- 动效不承载唯一信息；停止动画后文章仍完整。

## 8. Anti-slop 禁止项

- 旧版奶油亲子插画、暖纸纹理和固定左边线标题的复用。
- 任何文章都套同一5类组件，仅替换颜色。
- 三等分卡片、每节小标签+标题+说明的机械节奏。
- AI紫渐变、外发光、过量阴影、玻璃拟态万能化。
- 伪精确数字、无来源数据、虚构Logo/人物/用户评价。
- 重复CTA、重复金句、图片标签贴纸、装饰性英文元数据条。
- 大段正文图片化、低对比、小字号、过宽表格。
- 只有文字和色块却声称“极简高端”；缺真实或原创视觉就是未完成。

## 9. 视觉预检

- Design Read与三只旋钮已记录。
- 首屏在小屏上5秒内能说清主题，并有真实/原创主视觉。
- 视觉母题与核心信息存在因果关系。
- 至少3种节奏家族，没有同构区块连用3次。
- 只有一个强调色和一套形状规则。
- 图片角色、来源、比例、裁切和alt完整。
- 动效有理由、静态降级、体积与首帧检查。
- 无旧图/旧画风/旧布局借鉴，无常见AI设计套话。
- 375/390/430px、浅色/深色、微信复制和真机预览通过。
