# 优秀案例对标方法

案例只用于学习设计规律。不要下载、复制或重组他人的完整排版、插画和独特组件。

## 调研步骤

1. 判断赛道与读者。
2. 搜索近12个月同赛道的3–5篇公开文章；记录发布日期和原始URL。
3. 每篇只记录：首屏结构、正文宽松度、标题层级、组件密度、图文比例、配色和深色模式风险。
4. 总结共同规律与应避免的问题。
5. 为当前文章重新设计，不复刻任何单篇作品。

## 种子观察池

这些名称仅用于检索公开文章，运行时必须核验当前案例，不把下表当作事实背书。

| 赛道 | 可检索观察对象 | 重点观察 |
|---|---|---|
| 知识科普 | 果壳、丁香医生、混知 | 解释图、术语降噪、问答节奏 |
| 商业科技 | 晚点LatePost、36氪、虎嗅APP | 数据层级、引语、信息密度 |
| 生活美学 | 一条、物道、Canva设计 | 摄影比例、纸张感、留白 |
| 人物叙事 | 人物、真实故事计划、新世相 | 首屏情绪、长文停顿、人物引语 |
| 教程清单 | 少数派、运营研究社、秋叶PPT | 步骤、截图、提示与总结 |

## 离线参考方向

极简知识、数据发布、暖纸叙事、清新教程、杂志人物只作为起点。交付设计说明时注明“实时案例”或“离线种子参考”，不要伪装已联网调研。
