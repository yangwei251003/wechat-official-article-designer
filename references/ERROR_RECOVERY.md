# 错误恢复

| 失败 | 处理 | 继续输出 |
|---|---|---|
| 格式不支持 | 建议另存支持格式 | 文件清单与失败状态 |
| PDF无文本 | 页面截图/OCR | 原文件引用与警告 |
| OCR/转录缺工具 | 本地安装或用户提供文字稿 | 其他资料继续 |
| API Key缺失 | Mock/跳过/配置说明 | 不伪造结果 |
| 外部API超时 | 有限重试后降级 | 本地/生成/程序素材 |
| 未知许可证 | 阻断自动发布 | 版权报告与人工确认 |
| 恶意HTML/SVG | 清理或拒绝 | 安全静态版本 |
| 图表工具缺失 | 程序图/文字/保留规范 | 静态降级报告 |
| 微信错误 | 映射errcode、保留本地包 | 手工导入 |
| 草稿状态未知 | 保留pending，禁止重试 | 后台核对说明 |
| 锁定冲突 | 拒绝修改 | 未锁定部分继续 |

永远不要因为单个外部服务失败而停止所有离线能力。
