# 依赖与资产边界

|依赖|本机实测版本|上游许可/分发边界|
|---|---|---|
|Pillow|11.0.0|Pillow/HPND 许可；示例使用其默认字体，不分发微软字体|
|NumPy|2.4.4|BSD-3-Clause|
|OpenCV Python|4.13.0.92|OpenCV 主库 Apache-2.0，打包组件遵循各自许可；不捆绑二进制|
|`@oai/artifact-tool`|仅原适配器引用|由兼容宿主提供，不分发 SDK；本次未导入或测试|

Python 包作为外部依赖单独安装，根 MIT 不覆盖它们。无界面 OpenCV 安装项用于独立虚拟环境；本机实际调用了已有同接口 `cv2`。

源码整理移除了原照片输入清单、儿童/人员相关文案、真实文章内容、课程时间地点姓名、私人路径和配置。公开演示只含新造几何图、虚构正文和相应运行结果，未读取原图片、文章和课表正文。图像 EXIF 检查只针对这些新造合成文件。

宿主表格适配器只是 API 调用代码，不包含表格数据或第三方 SDK 源码。文档没有把它宣称为无需宿主即可运行的普通 Node 工具。
