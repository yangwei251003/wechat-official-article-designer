# 手工验收清单

- [ ] `source.md` 与用户原文、数字、人名、引用、段落顺序一致。
- [ ] 所有锁定节点、标题、数据和素材未被覆盖。
- [ ] `article.json` 通过 Schema 2.0。
- [ ] 三套视觉方向在布局、组件、图片与节奏上不同。
- [ ] Design Read、`DESIGN_VARIANCE`、`MOTION_INTENSITY`、`VISUAL_DENSITY` 和单一视觉母题已记录。
- [ ] 旧封面、旧插画、旧 GIF、旧组件与旧截图没有进入新设计参考、资产引用或 Design DNA。
- [ ] 高设计成品通过 `design-quality-report.json`；至少三种节奏、原创主视觉和两项微信可用原创资产。
- [ ] 所有第三方素材有作者、原始页、许可证、日期和署名；未知项阻断自动发布。
- [ ] 微信正文无脚本、style/link/iframe/svg/video、事件属性与危险 CSS。
- [ ] 375/390/430px无横向溢出；浅色/深色模拟可读。
- [ ] 复杂图表/动效/组件有静态降级，且不丢核心信息。
- [ ] 首屏 5 秒内说清主题；图片角色、alt、裁切和 GIF 首帧完整；没有基线排版冒充成品。
- [ ] 复制进微信公众号编辑器后图片成功转存；链接、表格、封面和摘要正确。
- [ ] 微信客户端预览通过后，才考虑真实草稿/发布。
- [ ] 无 Secret、Token、Cookie、绝对私人路径或完整私人正文进入日志/报告。
