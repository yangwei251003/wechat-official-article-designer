# 已知限制

1. 本示例已连接一套用户授权的真实公众号账号，并完成草稿创建和回读；自动测试仍只使用 Mock，其他账号必须自行完成权限和 IP 白名单验证。
2. 微信官方开发文档在当前网络环境无法直接打开，真实接口应在联调前再次核对。
3. PDF 扫描件 OCR、音视频转录需要本地工具或用户授权的外部服务。
4. CSS 内联只支持标签、单 class、单 id 选择器；复杂层叠需外部浏览器工具预处理。
5. 图表内置可重复 Mock/程序 SVG；Mermaid CLI可选，ECharts/Vega-Lite真实渲染未在本机安装验证。
6. 连接器只返回候选，Openverse/Wikimedia等聚合信息必须回到原始作品页核验。
7. `materials.py` 为防 SSRF 采用严格下载白名单，未列主机需要人工核验并显式扩展代码/测试。
8. `design_quality.py` 能阻断基线冒充、旧图引用和缺少原创资产等确定性问题，但不能证明传播效果；视觉质量仍需人类审美与微信真机检查。
9. 程序资产工厂擅长抽象概念、动态图形、信息母题和组件；真实人物、地点、产品摄影仍应使用用户素材、许可明确图库或图像生成工具，并保留来源/生成记录。
