# 关键决策

## D001 保留 v1 包契约

`article-package.json` 保持 1.0，新增 `article_schema_version` 与 `article_file`；核心内容进入 `article.json` 2.0。原因：避免破坏已有预览、素材和微信草稿脚本。

## D002 不开发网站/画布

Konva、Fabric.js、GrapesJS 只用于数据结构与未来渲染器研究，不成为当前依赖。

## D003 外部服务默认关闭

真实连接器需要 `--allow-network`，外部上传与微信真实写入另需用户明确授权。所有测试使用本地或 Mock。

## D004 不吸收受限源码

`md2wechat-skill` 当前许可证带商业与再分发限制；BlockNote XL 为 GPL-3.0。二者不成为依赖，也不复制代码、主题或提示词。

## D005 简单、可审计的编译链

使用 Python 标准库和已存在的轻依赖；CSS 内联器只承诺简单选择器。复杂网页先在浏览器/专用工具处理，再进入安全清理。

## D006 兼容优先级

安全/隐私/法律 → 用户锁定 → 微信稳定 → 事实与可读性 → 品牌 → 视觉 → 自动化。

## D007 图片与动效

SVG、Mermaid、ECharts、Vega-Lite、Lottie、Rive在微信端全部使用 SVG/PNG/GIF/视频或文字静态降级，不依赖正文 JavaScript。

## D008 外部素材不足时自主创作

不以空白占位结束。Skill作为网页艺术师和推文元素设计师，根据文章语义调用图像生成能力或`asset_factory.py`创作统一的封面、组件、背景、SVG和GIF；同时交付可编辑源与微信安全渲染版本。

## D009 旧图仅作反例基线

历史文章包、封面、插画、GIF、截图和旧装饰资产不进入Design DNA，不作为色彩、画风、组件或构图参考。保留它们只为证明v1兼容和识别需要淘汰的模式。新视觉从内容、读者、品牌和重新调研的案例开始。
